게시판 추가
게시글 목록의 각 행(row) 전체를 가리키는 CSS selector.
예) 테이블형: table.bbs_list tbody tr
예) 리스트형: ul.boardList > li
F12 → 게시글 행 우클릭 → Copy → Copy selector
위 행(row) 안에서 제목 텍스트와 링크가 있는 <a>를 가리키는 selector.
예) td.title a  |  .nttSj a  |  td:nth-child(2) a
'답글' 대신 특정 컬럼의 텍스트로 완료를 판단할 때 사용.
예) 4번째 칸이 '처리완료'라면: td:nth-child(4)
답변글 제목에 포함된 완료 표시 키워드.
예) 완료 → "답변글 (완료)Re: …", "답변글 Re: (완료) …" 모두 감지
여러 키워드가 있으면 한 줄에 하나씩 입력.
