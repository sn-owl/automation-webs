# 유지보수 게시판 모니터 — 개발 이력 (2026-04-28)

## 1. 프로젝트 개요
eGovFramework 기반 유지보수 게시판의 미처리 게시글을 자동 감지하여 텔레그램으로 알림을 보내는 크롬 확장 프로그램입니다.

## 2. 주요 업데이트 및 버그 수정 사항

### 🛠 버그 수정 (Bug Fixes)
- **답변글 인식 로직 개선:** 
  - 기존: "답변글"이라는 텍스트가 제목 앞에 반드시 있어야만 답변으로 인식 (하드코딩).
  - 수정: `Re:`, `[완료]`, `(완료)` 등 사용자가 설정한 `completePatterns`로 시작하면 모두 답변으로 인식하도록 유연화.
- **페이지 경계 오판 방지:**
  - 목록의 맨 마지막(15번째 등) 게시글이 '원글'일 경우, 답변이 다음 페이지에 있을 가능성을 고려하여 분석 대상에서 제외 (오탐지 방지).
- **텔레그램 MarkdownV2 전송 오류 수정:**
  - 제목에 특수문자(`(`, `)`, `[`, `]` 등)가 포함될 경우 전송이 실패하던 문제를 이스케이프 로직 보강 및 실패 시 일반 텍스트 재전송 로직으로 해결.

### ✨ 신규 기능 (New Features)
- **상태값 기반(컬럼) 완료 판단:**
  - 게시판 설정에 `상태값 Selector` 추가.
  - 답글 유무가 아닌, 특정 컬럼(예: 진행구분)의 텍스트가 "처리완료"인지 직접 확인하는 모드 지원.
- **게시글별 알림 보류 (Mute/Snooze):**
  - 현황 탭의 게시글 옆 **🔕 아이콘** 추가.
  - 클릭 시 해당 글은 노란색으로 강조되며, 미처리 건수에서 제외되고 텔레그램 알림도 오지 않음.
  - 브라우저를 껐다 켜도 유지되는 영구 보류 방식 적용.
- **텔레그램 알림 ON/OFF 스위치:**
  - 설정 탭에서 텔레그램 알림을 완전히 끄거나 켤 수 있는 전역 스위치 추가.

## 3. 게시판별 설정 가이드

### A. 답글 방식
- **상태값 Selector:** 비워둠.
- **완료 키워드:** `완료`, `처리완료` 등 (답변글 제목에 포함될 단어).
- **동작:** 원글 제목과 대응하는 `Re: 완료 ...` 형태의 답변이 있는지 확인.

### B. 상태값 방식
- **상태값 Selector:** `td:nth-child(4)` (진행구분 컬럼 위치).
- **완료 키워드:** `처리완료`.
- **동작:** 4번째 칸의 텍스트가 "처리완료"가 아니면 무조건 미처리로 간주.

## 4. 기술적 특징
- **Offscreen Document:** `DOMParser`를 사용하여 백그라운드에서 안전하게 HTML 분석.
- **Smart Fetch:** 일반적인 fetch 실패 시, 현재 브라우저에 열린 탭의 세션을 이용하여 데이터 수집 시도.
- **State Persistence:** `chrome.storage.local`을 사용하여 게시판 설정, 보류 목록, 이전 스캔 상태를 영구 저장.
