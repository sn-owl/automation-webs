# 무더위쉼터 HWPX → XLS 변환기

> **범위 안내.** [아키텍처 문서](../docs/ARCHITECTURE.md)의 **S7-C 준비 수행**에 해당하는 Executor 구현 예시 하나다.
> 입력 양식과 실행 환경 제약은 이 변환기의 한계이지 Core가 다룰 수 있는 업무 도메인의 한계가 아니다.

무더위쉼터 현행화 신청서의 표를 읽어 고정 업로드 양식 `restarea-template.xls`에 채웁니다. 문서와 결과 파일은 로컬 PC에서만 처리합니다.

## 지원 범위

- 입력: `.hwpx`
- 출력: Excel 97–2003 `.xls`
- 처리: HWPX 표 탐색, 열 재배치, 셀 내부 줄바꿈과 공백 보존
- 제외: 게시판 다운로드, 관리자 페이지 업로드, `.hwp` 자동 변환

`.hwp` 파일은 한글에서 **다른 이름으로 저장 → HWPX**를 선택한 뒤 사용하세요.

## 다른 컴퓨터에서 사용하기

### 준비물

- Windows 10 또는 11
- Python 3.10 이상
- Microsoft Excel

### 설치

1. `restarea-converter` 폴더 전체를 다른 컴퓨터로 복사합니다.
2. `setup.bat`을 한 번 실행합니다.
3. 설치가 끝나면 창을 닫습니다.

설치 과정은 Excel 제어에 필요한 `pywin32`만 추가합니다.

### 변환

HWPX 파일을 `convert.bat` 위로 끌어다 놓습니다. 입력 파일과 같은 폴더에 다음 이름으로 결과가 생깁니다.

```text
<입력 파일명>-restarea.xls
```

명령 프롬프트에서는 다음처럼 실행할 수 있습니다.

```bat
py converter.py "신청서.hwpx" -o "restarea.xls"
```

다른 템플릿을 지정하려면:

```bat
py converter.py "신청서.hwpx" -o "restarea.xls" --template "다른양식.xls"
```

## 확인 방법

1. 생성된 XLS를 Excel로 엽니다.
2. 첫 행 제목이 `무더위 쉼터 현황`인지 확인합니다.
3. 두 번째 행의 열 순서를 확인합니다.
4. 행 수와 줄바꿈이 신청서 표와 맞는지 확인합니다.
5. 관리자 페이지에는 사람이 최종 확인한 파일만 업로드합니다.

출력 열은 다음과 같습니다.

| 출력 열 | HWPX 열 |
|---|---|
| 번호 | 연번 |
| 쉼터명 | 시설명 |
| 주소 | 주소 |
| 연락처 | 대표전화 |
| 해당동 | 해당동 |
| 운영시간 | 운영시간 |
| 운영요일 | 운영요일 |
| 해당동 | 해당동 |

## 동작 방식

```text
HWPX
  → Contents/section0.xml 읽기
  → 연번·해당동·시설명·주소·운영요일·운영시간·대표전화 헤더를 가진 표 탐색
  → 데이터를 고정 열 순서로 변환
  → 빈 XLS 템플릿 복사
  → 3행부터 데이터 기록
  → 새 XLS 저장
```

표의 위치나 순서는 고정하지 않습니다. 필요한 헤더가 모두 있는 표를 찾아 사용합니다. 해당 표가 없거나 두 개 이상이면 잘못된 파일 생성을 막기 위해 중단합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `converter.py` | 파싱, 검증, XLS 생성, CLI |
| `restarea-template.xls` | 고정 업로드 양식 |
| `convert.bat` | HWPX 끌어다 놓기 실행 |
| `setup.bat` | Python 의존성 설치 |
| `requirements.txt` | 고정된 Python 의존성 |
| `test_converter.py` | 파서와 XLS 생성 계약 검사 |

## 테스트

```bat
py -m unittest -v test_converter.py
```

테스트는 다음을 확인합니다.

- 헤더 이름을 기준으로 데이터 표를 찾는지
- 셀 끝 공백과 문단 줄바꿈을 보존하는지
- 고정 XLS 템플릿에 올바른 순서로 기록하는지

## 문제 해결

### `No module named win32com`

`setup.bat`을 실행하세요.

### Excel을 실행할 수 없다는 오류

Microsoft Excel이 설치되어 있는지 확인하세요. 이 변환기는 `.xls` 양식을 유지하기 위해 Excel COM을 사용합니다.

### `.hwp`를 넣었더니 중단됨

한글에서 파일을 HWPX 형식으로 다시 저장하세요. 이번 Recipe는 HWP 바이너리를 직접 읽지 않습니다.

### 표를 찾지 못함

신청서 표에 다음 헤더가 존재하는지 확인하세요.

```text
연번, 해당동, 시설명, 주소, 운영요일, 운영시간, 대표전화
```

양식 자체가 바뀌었다면 변환기를 억지로 실행하지 말고 새 양식을 먼저 분석해야 합니다.

## 제한사항

이 폴더의 변환기는 한 가지 Recipe의 구현 예시다. 변환기 자체의 한계는 저장소 전체의 도메인 한계가 아니다.
